GitHub Token
Optional

See your open PRs, review requests, assigned issues, and notifications right in the dashboard.

How to create a token:
  1. Go to github.com/settings/tokens
  2. Click Generate new token (classic)
  3. Name it "Janjak", select scopes: repo + notifications
  4. Click Generate and paste the token below
3
Google Calendar & Email
Optional

Connect Google to see your calendar in the dashboard, get meeting alerts, and scan emails for tasks.

How to set up Google:
  1. Go to Google Cloud Console → Credentials
  2. Create a project (or use an existing one)
  3. Enable Gmail API + Google Calendar API
  4. Create OAuth 2.0 Client ID (Desktop app)
  5. Download the JSON file and paste its contents below
After saving credentials, click Authenticate to authorize Janjak. A browser window will open for Google sign-in.
